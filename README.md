# UTM Jr. Apprentice Program — Inbound Marketing Cohort

Repository for my work in UTM's Q4 2026 Marketing Apprentice Program,
placed on the Outbound Marketing team.

## About the Program
UTM (formerly Austin Urban Tech Movement) runs a structured apprenticeship:
a 3-month unpaid Junior Apprentice cohort, followed by paid Senior Apprentice,
Field Staff, and Management tracks. The program culminates in a final campaign
presentation at Rethink Austin (November 14, 2026).

## What's in this repo
Campaign strategy documents, outbound marketing assets, and project work
produced during the apprenticeship.
